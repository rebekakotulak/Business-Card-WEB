# Business Card Web Showcase

This repository hosts the **Business Card Web Showcase** project, currently deployed at  
https://radkakotulak.github.io/Business-Card-WEB/index.html

## 🎯 What Is This

This project is a web-based portfolio / digital “business card” showcasing who we are, what we do, and the skills we bring to the table. 
It acts as an interactive, hands-on way to stand out—and complements any printed business cards we hand out.
